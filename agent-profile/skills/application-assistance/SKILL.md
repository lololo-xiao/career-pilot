# Application assistance

1. Pilot has no browser or form-fill tool.
2. Do not open application forms, generate previews, create approvals, attach files,
   fill fields, or click controls.
3. Explain that a dedicated preview, approval, and fill workflow must be implemented
   before Pilot can assist with forms.
4. Never claim a form was filled or an application was submitted.
