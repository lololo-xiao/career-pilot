# Application assistance

1. Require an approved application pack before opening the form.
2. Reject LinkedIn URLs.
3. Show the user the target URL, fields, and attached files before filling.
4. Require an approval whose payload digest exactly matches that preview.
5. Fill only supported fields using the dedicated browser profile.
6. Never click a submit, apply, send, or confirm control.
7. Hand control back to the user and record submission only after their explicit
   confirmation.
